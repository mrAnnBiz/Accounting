Potential Issues Identified

ISSUE #1: Input Method Detection Conflict
Problem: How do we distinguish between:
Stylus (Apple Pencil) = should annotate when tool selected
Touch finger = should ALWAYS scroll, never annotate
Mouse = should annotate when tool selected
Current System Risk: The canvas might not know if it's a stylus or finger, leading to:
Accidental annotations from fingers
Inability to scroll on iPad when stylus is being held
Solution Required:
Research the Stylus vs touch treatement by ipad, touchscreen laptops.
Detect pointerType from PointerEvent (stylus vs touch)
For touch events: BLOCK annotation, ALLOW scrolling
For stylus/mouse: ALLOW annotation IF tool selected, ALLOW scrolling if NO tool selected


ISSUE #2: Scroll vs Annotate State Machine
Problem: Your requirement seems to require different behavior for stylus:
Stylus + No tool selected = SCROLL
Stylus + Tool selected = ANNOTATE
Current System Risk: How does the component know if a stylus drag is "scroll intent" vs "annotation intent"?
Solution :
Implement a state machine: touchState = 'scrolling' | 'annotating' | 'idle'
On stylus down + NO tool = assume scroll, activate pan mode
On stylus down + TOOL SELECTED = annotate
